# Reimagining Civic Tech DC: A Personal Vision for 2027

A responsive two-page website presenting **Helen Y. Glover's personal working vision** for Civic Tech DC in 2027.

## About

The vision explores three connected directions:

- **Make knowledge public:** expand the Civic Tech DC Playbook, share case studies, and explore a DC civic innovation ecosystem map.
- **Create pathways to participate:** workshops, contributor development, and potential workforce partnerships.
- **Give ideas room to grow:** explore Civic Innovation Labs and an incubator pathway.

The guiding idea is to **gather, experiment, share, and repeat**—turning lessons from community events and projects into resources others can use.

**Note:** This is an independent, exploratory perspective by Helen Y. Glover, not an officially adopted Civic Tech DC strategic plan. Proposed initiatives and partnerships are not commitments.

## View locally

Open `index.html` in any browser. It has no build process or external dependencies.

## Publish with GitHub Pages

In the repository, visit **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Program areas

[Three Pillars](three-pillars.html) preserves Helen’s supplied Projects, Workforce,
and Education notes, with the Advisory Board as a cross-cutting initiative.
It includes the contributor journey-map description, mini-project ideas,
onboarding lead, Lab and working groups, quarterly showcases, potential workforce
initiatives and partners, proposed leads (including “Cameron (?)”), and Academy.
The original overview and 2027 outline remain in `index.html`.

Only grammar, spelling, and formatting corrections were made to the supplied
program text. The original journey-map diagram and the referenced
`guide_to_civic_tech_and_data_ecosystem_mapping.pdf` were not supplied.
“Review Civic Tech Resources” was supplied without a URL; resource names remain
visible rather than linking to guessed destinations.

No dependencies or installation are required. For a local server, run
`python -m http.server 8000 --bind 127.0.0.1` from this repository.

Validation: both pages were checked in Chromium at 320, 390, 768, and 1440 pixel
widths for horizontal overflow and valid section anchors. Navigation from the
overview to Three Pillars and back was exercised. External destinations were not
verified because the environment’s outbound proxy was unavailable.
